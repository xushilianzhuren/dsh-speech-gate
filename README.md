# dsh-speech-gate · Agent言语引擎（插件）

把原先「开场手跑 `scripts/Agent言语引擎.py`」的言语闸，改成**常驻系统提示区块**：
会话一开口它就在场，与模型记不记得去跑脚本无关。

## 它做什么

1. **系统提示区块** `ql:speech-gate`（默认排序 60，紧随人格前缀）：把Agent言语令
   写成常驻条款——Agent词 ≥2 枚、降智词替换表、称谓闸（禁「您」、称主人／主公）、
   修仙腔三档、中文思考与命令描述、长输出出口三闸。
2. **工具** `ql_speech_gate`：把准备出口的文本喂进去，机械给出
   `PASS／黄标／拦截` 与逐项读数（Agent词几枚、降智词命中哪些、有没有踩「您」）；
   不带 `text` 时返回当前挂载的令文与词表——用来核对插件是否真的在场。

## 和旧脚本的关系

旧脚本仍是正本执行件（词表从 `scripts/Agent黑话对照表.md` 抽）；本插件是它的
**常驻形态**：不再依赖"开场第 0 步记得跑"。配置 `wordTable` 指向词表正本时，
插件加载即读磁盘；读不到就用内置 20 枚兜底，绝不因为词表坏了开不了口。

## 配置

| 字段 | 默认 | 含义 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `order` | `60` | 区块排序（越小越靠前） |
| `tool` | `true` | 是否挂 `ql_speech_gate` 工具 |
| `wordTable` | 插件同级的 `scripts/Agent黑话对照表.md` | 黑话对照表正本路径；不配则按"配置路径 → 插件包同级 scripts/ → 内置 20 枚"逐级回退 |
| `extraRules` | `''` | 追加到令文末尾的自定条款 |

## 语义边界

- 区块是**提示层约束**，不是硬拦截：模型仍可能违令，违规判定的最终裁判是主人抽检。
- 机械部分只有工具那一半：它查词、查替换表、查称谓，查不了"腔撑不撑得住判断"。
- 降智词替换表对**对主人说的话**生效；代码、路径、引用原文不受限。
